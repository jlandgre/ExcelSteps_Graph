Because pivot tables have a predictable structure based on their rowFields and colFields and analytes, they can be described by a `tblPivotTabular` object.

In xlTabularRow layout, the example below shows the structure if 
* The Values column is specified as first rowField. `DataPivotFieldPosition` is 1 (e.g. first) position `DataPivotFieldOrientation` is `xlRowField` 
* `prodtype` is a rowField (and moves to position 2 because of `DataPivotFieldPosition`)
* `year_hist` and `wk_serial_hist` are colFields

Coule define a `tblPivotTabular` object
* `wkbk`, `wksht`, `sht` attributes
* .rowColFieldNames = 1
* .colHomeColFieldNames = 3
* .rngColFieldNames = C1:D1
* n_ColFields = 2
* .rowRowFieldNames = n_ColFields + 1
* n_RowFields = colHomeColFieldNames - 1
* DataPivotFieldOrder = 1 (because of "Values" in first cell of .rngColFieldNames)
* .rngRows = 4:15
* .rngDataCols = C:J
* .rngTable = A1:J15
* .rngColFieldHeaders = C2:J3

To structure the table:
* Fill down Values column data
* Insert a `metric` column based on regex to read "Sum" from Values column
* Convert Values column data to field names (sales_hist, Discounts etc.)
* Move rowFields and data down one row (to leave blank cells above first row of data)
